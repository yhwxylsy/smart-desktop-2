## 图例

| 符号 | 含义 |
|---|---|
| `────` | 总线 / 连接 |
| `◄──►` | 双向 / 全双工 |
| `──►` | 单向 |

## 总线清单（按类型归纳）

| # | 总线 | 挂接设备 | 关键参数 |
|---|---|---|---|
| 1 | **I2C** ×1 | OLED + AHT20（STM32 侧） | 400kHz，地址 `0x3D` / `0x38` |
| 2 | **UART** ×4 | STM32↔ESP32 全双工 / SYN6288 / USB 调试 / ESP32 收发双口 | 115200 / 9600 / 115200 |
| 3 | **SPI** ×1 | RC522（ESP32 侧） | MFRC522 库 |
| 4 | **I2S** ×1 | PDM 麦克风（ESP32 侧） | 16kHz/16bit |
| 5 | **PWM** ×3 | 风扇 / 蜂鸣器 / 舵机（STM32 侧） | 舵机为软件 50Hz |
| 6 | **ADC** ×2 | NTC / 电位器（STM32 侧） | 10bit |
| 7 | **GPIO** 若干 | RGB / 循迹 / 编码器 / 按键 / 继电器 / 超声波 | 数字 I/O |
| 8 | **WiFi** | ESP32 ↔ 云端 | 802.11，HTTPS+WS |

## 一句话记忆

- **STM32** 负责"感知 + 执行"，用 I2C（2 个传感器）、UART（3 路）、PWM、ADC、GPIO。
- **ESP32S3** 负责"联网 + 桥接"，用 WiFi、SPI（RFID）、I2S（麦克风）、UART（连 STM32）。
- 两块 MCU 之间只靠 **1 条 UART 全双工链路**（115200）交换 `NET:*` 命令和 `BT:*` 回执。
